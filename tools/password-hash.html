Préparer un mot de passe

Ouvre ce fichier sur ton ordinateur. Le mot de passe reste dans ce navigateur : aucun appel réseau n’est effectué. Cet outil ne crée aucun compte.

PBKDF2-HMAC-SHA-256 · 600 000 itérations · sel aléatoire de 128 bits. La connexion PHP convertira ensuite cette empreinte en bcrypt lorsque le mot de passe le permet.
